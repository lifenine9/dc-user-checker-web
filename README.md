# 디시 활동 확인기

갤러리 + 고정닉 식별코드를 입력해 최근 게시글 범위에서 작성 게시글을 찾는 웹앱입니다.

## 실행

```bash
npm.cmd install
npx vercel dev
```

브라우저에서 Vercel이 안내하는 로컬 주소를 엽니다.

## 현재 포함된 기능

- 총공빌더와 같은 방식의 DCInside 갤러리 자동완성 검색
- 일반 / 마이너 / 미니 갤러리 구분
- 식별코드 입력
- 최근 1,000 / 5,000 / 10,000 / 20,000 / 50,000개 선택
- 게시글 작성자 userId 검사
- 일치하는 게시글 번호 출력
- 게시글 번호 클릭 시 해당 글 열기
- 댓글 검사 버튼 UI(아직 실제 검사는 연결 전)

## 참고

게시글 검사 로직은 현재 로컬에서 검증한 `@gurumnyang/dcinside.js` 기반입니다.
